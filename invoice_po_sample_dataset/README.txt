Synthetic Invoice + PO Test Dataset

Each case contains:
- invoice.pdf
- purchase_order.pdf

Expected cases:
1. case_01_match - exact match
2. case_02_price_variance - invoice unit price differs from PO
3. case_03_quantity_variance - invoice quantity exceeds PO quantity
4. case_04_currency_mismatch - invoice currency differs from PO
5. case_05_vendor_mismatch - invoice vendor differs from PO

PNG versions are added separately by rendering the PDFs.
All documents are synthetic and safe for prototype testing.
